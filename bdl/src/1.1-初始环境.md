# 1.1 初始环境

本项目是按照TIPTOP GP写的，但T100原理相同，但是T100有一层额外封装，开发起来多有限制，但原理相同。 

## 服务器

TIPTOP GP 服务器通常部署再一台`RedHat`服务器上，如我这台是一个`RedHat6.5`版本的服务器。

```bash
# 内核版本
➜ uname -r
2.6.32-431.el6.x86_64

# 默认GCC版本 4.4.7
# 如果要使用CGo后续要安装新版本GCC
cat /proc/version
Linux version 2.6.32-431.el6.x86_64 (mockbuild@x86-023.build.eng.bos.redhat.com) (gcc version 4.4.7 20120313 (Red Hat 4.4.7-4) (GCC) ) #1 SMP Sun Nov 10 22:19:54 EST 2013

# 发行版本
➜ cat /etc/redhat-release
Red Hat Enterprise Linux Server release 6.5 (Santiago)
```

## SHELL

TIPTOP GP 中默认的`shell` 是一个叫做`ksh` （`KornShell`）的工具，这个`shell` 是一个成熟的`UNIX` 时代的工具，现在 `linux` 流行的`bash` 都是发源自 `ksh` 。

不建议修改默认`shell`，许多自动话脚本都依赖这个`ksh` 。但是后面我们可以再运维开发的时候使用更现代的`shell` ，遇到问题可以切换回`ksh` 。

```bash
# 默认SHELL
➜ echo $SHELL
/bin/ksh
```

## 重要环境变量

TIPTOP GP 中有大量的定制的环境变量，部分是 Genero Bussiness Development Language(BDL) 环境所需要的，有的是TIPTOP GP定制的。

下面只列出部分经常用到见到的环境变量。

### 便利性环境变量

```bash
# cd 切换目录时，遍历这个环境变量，可以实现任意位置，都能快速切换到这些目录下面的目录。
# 例如：cd axc 可以任意目录切换到/u1/topprod/tiptop/axc 目录
CDPATH=.:/u1/topprod/topcust:/u1/topprod/tiptop:

# 分别是模组目录，和目录的可执行文件路径，用来简化目录配置
AIM=/u1/topprod/tiptop/aim
AIMIi=/u1/topprod/tiptop/aim/42r

# 常用脚本目录
TMTDIR=/u1/tmt

# 临时文件目录
TEMPDIR=/u1/out

# 标准和客制程序根目录
TOP=/u1/topprod/tiptop
CUST=/u1/topprod/topcust

# 配置文件目录
TOPCONFIG=/u1/topprod/tiptop/config
```

### 重要环境变量

```bash
# 可执行文件执行程序
FGLRUN=fglrun

# Genero 的运行环境，这个很重要，后面有很多地方会用到
FGLDIR=/u1/genero/fgl.dev
# 还有一些 FLMDIR GREDIR GSTDIR 是一些Genero配置需要的一些授权等环境变量，这里不列出了。
# 因为我们运维不能修改这些内容。开发也用不到

# Genero 的可执行文件路径变量，类似C的LD_LIBRARY_PATH，一般是所有模组的42m目录
FGLLDPATH=...

# 
```

### 数据库相关的一些环境变量

```bash
# oracle 客户端安装路径
ORACLE_HOME=/u2/oracle/product/11.2.0/dbhome_1

# 数据库用户（用户对应TIPTOP 中的营运中心，T100中不是）配置文件
FGLPROFILE=/u1/genero/fgl/etc/fglprofile.prod

# 存放一些数据库查询脚本sql
SQLPATH=.:/u1/topprod/tiptop/ora/scripts:

ORACLE_SID=topprod
```

### JAVA环境

```bash
# javahome
JAVA_HOME=/opt/java
```

### 其它一些变量

```bash
# web服务地址
FGLASIP=http://192.168.1.19/topprod

# 终端的颜色配置
TERM=xterm-256color
```
