# 1.2 常用工具介绍

## 编译&链接&调试&运行

```bash
# 将 .4gl 文件编译为 .42m 文件,依赖fglcomp命令 
# 在当前目录的 ../4gl 目录找4gl文件，.42m 文件放到 ../42m 目录下
r.c2 axcp500 
 
# 将 .4fd 文件编译为 .42f 文件，依赖gsform、fglform
# 在当前目录的 ../4fd 目录找4fd文件，.42f 文件放到 ../42f 目录下
r.f2 axcp500
 
# 预览画面档，并根据sch将字段说明文字写入p_perlang/p_per作业中，2表示中文
r.gf axcp500 2 p
 
# 此命令依赖数据库配置，会查看p_link中的链接资料
# lib sub qry 模块是可以直接链接的，在p_link中维护链接资料
r.l2 axcp500 
 
# 运行当前目录 ../42r/axcp500.42r 程序
r.r2 axcp500
 
# 由 p_po 判定目录位置，任意目录都能执行的axcp500
exe2 axcp500
 
# 调试目录 ../42r/axcp500.42r
r.d2 axcp500
# 同上，但是会启动前端调试界面而非cli调试界面
r.d2+ axcp500
  
# 产生 ds库的sch文件
r.s2 ds

# 将axcp500.per 转为 axcp500.4fd 文件，生成在per文件所在目录
gsform -M -import axcp500.per
```

## 3. 连接方式
- `ssh ${BDL_SSH_ALIAS}`（密钥登录，别名已配好）。**不要用 `printf | ssh -t`**，不弹伪终端且噪音大；非交互式不弹环境菜单，无需输入 `1`。
- `${BDL_SSH_ALIAS}` / `${BDL_TARGET_HOST}` / `${BDL_TARGET_USER}` 等变量由 `config/delivery.env` 提供（T10）；交付到新环境时覆盖该配置即可。
- **必须先 source 环境再 cd**：`. /u1/usr/profile/profile.topprod` 会把工作目录改到 `/u1/topprod/tiptop`，写在后面的 `cd` 会被覆盖，导致编译在错误目录执行、只报 `xxx error happens, check if: 1) Do you specify the right program name ?`。

## 4. 编译命令
- **4gl**（工作目录 = 模块 4gl 目录）：
  ```bash
  ssh ${BDL_SSH_ALIAS} '. /u1/usr/profile/profile.topprod >/dev/null 2>&1; cd /u1/topprod/topcust/crm/4gl/ && r.c2 crmt540 && r.l2 crmt540'
  ```
  含 `MAIN` 函数才追加 `r.l2` 链接。
- **per**（工作目录 = 模块 per 目录，不是模块目录）：
  ```bash
  ssh ${BDL_SSH_ALIAS} '. /u1/usr/profile/profile.topprod >/dev/null 2>&1; cd /u1/topprod/topcust/crm/per/ && r.p crmt540'
  ```
